# 版本变更日志 (Version Log)

本项目遵循 [语义化版本 2.0.0](https://semver.org/lang/zh-CN/) 规范。

---

## [v1.0.2] - 2026-10-28

### 🐛 缺陷修复 & 架构适配
- **适配 yt-dlp 官方更新策略**：针对 yt-dlp 官方对 pip/wheel 安装包禁止使用 `-U` 自更新的问题，在 `downloader.py` 中新增 `is_pip_ytdlp()` 智能探测逻辑，根据安装途径动态路由：
  - **pip 安装环境**：自动通过 `python -m pip install -U yt-dlp[default,curl-cffi]` 执行平滑升级，并自动透传已配置的代理参数；
  - **独立单文件二进制环境**：调用 `yt-dlp -U` 自更新；
  - **降级容错**：当二进制自更新发生异常时，自动回退到 pip 更新尝试。
- **修复更新反馈机制**：重构 `update_ytdlp()` 使其返回执行状态布尔值，主菜单选项 `[8]` 根据实际结果提示绿色成功信息或红色失败信息，杜绝在执行报错后误报“更新完成”。
- **多语言支持补充**：在中文（`zh_CN`）与英文（`en_US`）语言包中补充了 `update_failed` 国际化提示。

## [v1.0.1] - 2026-09-06

### ✨ 新增特性
- **播放列表下载自动分目录**：执行选项 `[2]`-`[4]`（整列下载、连续片段下载、指定集数下载）时，自动在目标保存目录下以**播放列表标题**创建独立子文件夹，该列表的所有文件自动归入其中。
- **无侵入设计**：通过命令行参数临时覆盖 `--output` 实现，不影响单个视频等其他下载任务，也不改写持久化配置文件。
- **智能复用**：重复下载同一播放列表时自动复用已建目录，避免目录冗余。

---

## [v1.0.0] - 2026-05-08

### 🎉 首次公开发布
- **Profile 多配置系统**：支持多套独立 profile，支持一键切换。
- **分层配置管理**：支持 Base 全局配置与 Profile 子配置分层覆盖。
- **精细化下载菜单**：支持单个视频、完整播放列表、区间片段（range）、离散集数（items）下载。
- **保留音频快捷切换**：提供提取并保留音频的开关选项。
- **全平台自动化安装**：提供 `install.py` 自动化部署脚本，支持 Windows、Linux 与 macOS。
- **系统集成**：支持自动生成桌面快捷方式与环境变量注入。
